# Product Strategy Audit — Crime Genome Redesign

## Core Problem
30+ panels treated as equal. No investigation lifecycle flow. ZIA is a feature, not the center.

## Investigator Workflow (the real product)
```
Intake (MyDay) → Correlate (ZIA Brief) → Investigate (Case Workspace) → Theory → Chargesheet
```

## What Judges See in 30 Seconds
1. Clean landing → "Investigation Operating System" (not "analytics dashboard")
2. Login → MyDay shows priority cases (not a card grid of 15 panels)
3. Click case → Case Workspace with 8 tabs (investigation-grade)
4. ZIA Brief → AI explains WHY, not just WHAT
5. Entity Graph → Network visualization (the wow moment)
6. Theory Board → Prosecution-ready hypothesis tracking
7. Chargesheet → Auto-generated with BNS sections

## What to Cut
- 15 analytics panels are NOT the product — they're supporting tools
- "Analytical Catalog" sidebar section with 9 items is overwhelming
- Generic "Welcome to KSP Dashboard" header
- Indigo/purple gradient in DailyBrief (should be navy)
- "SCRB Network · Secure Node" filler text

## What to Keep
- All 15 analytics panels (they exist, they work)
- Case Workspace 8-tab structure (investigation workflow)
- ZIA conversational AI (Challenge 01 core)
- Public Deterrence Dashboard (Challenge 02 extra credit)
- Real-time RightSidebar alerts

## Priority Order for Judges
1. **Landing Page** — "Investigation OS" narrative ✓ (done)
2. **MyDay** — Focused case queue, not card grid
3. **Case Workspace** — Investigation-grade ✓ (done)
4. **ZIA Brief** — AI intelligence synthesis
5. **Entity Graph** — Network visualization wow
6. **Analytics** — Supporting panels (15 total)
7. **Chargesheet** — Auto-generation
